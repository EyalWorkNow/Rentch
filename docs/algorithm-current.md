# Rently — האלגוריתם הנוכחי (סיכום)

תיאור המצב אחרי שלב-1 (פרוס). בלי השוואות — היכולות כפי שהן.

## חלק א' — העוזרים

### 1. אריק — העוזר האישי
Gemini (gemini-2.5-flash), טקסט + קול, לבעלי דירה ולשוכרים.
- **לולאת כלים (function-calling):** כלים אמיתיים — `search_listings` (שאילתת DB אמיתית: עיר/חדרים/מחיר/שכונה/חיות) + `create_property` (טיוטת דירה לפרסום). עד 5 סבבים: מחליט → קורא לכלי → תוצאות אמיתיות → עונה על בסיסן.
- **Grounding:** עונה רק מתוצאות הכלים, לא ממציא דירות.
- **חילוץ (`/assistant/extract`):** responseSchema (JSON Schema + enums) → טיוטה מובנית מעברית חופשית.
- **קול:** STT מכשיר (he-IL) → Gemini → Gemini TTS (Kore, fallback ל-TTS מכשיר) → מקשיב שוב. turn-based (streaming חסום חיצונית).
- **פרסום:** טיוטה → תמונה → "הדירות שלי".

### 2. עוזר החיפוש (NL)
שורת חיפוש בשפה טבעית (הקלט הראשי בגילוי): טקסט חופשי → Gemini extract → `SmartSearch.parse` → `SearchFilters` → החבילה מסננת/מדרגת חי. פירסור on-device גיבוי; מתקנים = העדפה רכה.

### 3. "שאל את Rently"
Q&A לדירה בודדת: שאלה → `/listing/ask` מרכיב את הדירה + ההעשרה כהקשר יחיד → Gemini עונה grounded בעברית.

## חלק ב' — אלגוריתם חיפוש הדירות
1. **הבנת שאילתה** → `PropertySearchCriteria`.
2. **אחזור** → מאגר הדירות, סינון-עיר, דף חסום.
3. **סינון קשיח (לקוח)** → פעיל · עיר · מחיר · חדרים · מתקנים.
4. **דירוג לינארי שקוף:** tag_overlap 0.30 · price_fit 0.25 · popularity_prior 0.15 · recency 0.12 · distance_decay 0.10 · explore 0.08 → `Σ wᵢ·featureᵢ`. השרת מוסיף `rankSignals`.
5. **תיעוד** `/search/log` → סט אימון עתידי (LightGBM).
6. **העשרה (על create):** geocode + ציון-שכונה + מגמת CBS + smart-tags.
